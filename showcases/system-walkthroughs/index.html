02 · REUSE THE COMPONENTS

Explain another system.

The system-walkthrough skill provides an evidence workflow, one authoring model, a validator and a shared renderer. Agents collect and distill the source; the components handle the diagrams and interactions.

Install in Codex

git clone https://github.com/EvanOman/claude-skills-public.git
mkdir -p ~/.codex/skills
cp -R claude-skills-public/skills/system-walkthrough \
  ~/.codex/skills/system-walkthrough

Use a destination that does not already contain a copy of the skill. Refresh the skill catalog after installation.

Or install the Claude Code plugin

/plugin marketplace add EvanOman/claude-skills-public
/plugin install evan-skills@evan-skills

Ask Codex to use $system-walkthrough, or invoke /evan-skills:system-walkthrough in Claude Code, with a repository, a reader question and a bounded behavior.

Author once, build a portable page

cd claude-skills-public
node skills/system-walkthrough/scripts/walkthrough.mjs \
  init model.json
# Replace the starter with researched system content.
node skills/system-walkthrough/scripts/walkthrough.mjs \
  validate model.json
node skills/system-walkthrough/scripts/walkthrough.mjs \
  build model.json output

Authoring requires Node 22 or newer. The generated output/index.html embeds its content, styles and renderer. Reading needs only a browser, including from a local file.

  • Choose a map, walkthrough, sequence, or the combination that answers the question.
  • Record claims and primary-source pointers alongside nodes, edges, steps and state snapshots.
  • Reuse SystemWalkthrough.mount(element, model) when embedding the components in an existing page.

03 · EVIDENCE AND LIMITS

Read the source behind each step.

The guides cite implementation files at these fixed revisions. Each document also identifies live documentation, preconditions, illustrative scenarios and material simplifications. The selected sequence is one ordering of events; it does not establish that concurrent operations always occur in that order.

Valkey 9.1.329173b67508b2de4c0f0ed551f3b47cf19fc3ca8
SQLite 3.54.157520227c95396ce39ba6ecaac8d475b78dd3964

These are source-derived explanations, with no runtime telemetry or measured timings. They cover the configurations stated in each guide; other versions, deployment choices and failure conditions can change the behavior.
