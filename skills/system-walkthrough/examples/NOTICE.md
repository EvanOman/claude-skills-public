# Example provenance

The JSON models contain newly authored explanations and diagrams, with primary
source links. They do not bundle upstream implementation code or documentation.

- `starter.json` paraphrases HTTP Caching, RFC 9111, from the HTTP Working Group's
  repository at `bde37f634681bd5462568b73aa722af9c9a3ef5e`. The RFC and its source
  retain IETF Trust terms; no specification license is replaced by the tooling's MIT license.
- `valkey.json` describes Valkey 9.1.3 at
  `29173b67508b2de4c0f0ed551f3b47cf19fc3ca8`. Valkey source is BSD-3-Clause;
  its copyright and license notices remain in the linked upstream repository.
- `sqlite.json` describes SQLite 3.54.1 at
  `57520227c95396ce39ba6ecaac8d475b78dd3964`. SQLite core source is public domain;
  separately licensed upstream build/configuration files are not included here.

Live documentation is identified in each model's source notes. Example values and
interleavings are explicitly illustrative. New tooling, model prose and diagrams
are covered by the skill-local MIT license; third-party material retains its terms.
